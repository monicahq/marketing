Se você tem as habilidades e a vontade de operar a Monica por conta própria, acho ótimo.

Sim, isso pode significar um cliente a menos para o nosso serviço hospedado. Não, não revelei sem querer uma falha no plano de negócios.

O objetivo da versão hospedada é a conveniência para quem quer que a operemos. Ela não deveria exigir que fingíssemos que rodar o próprio software é uma má ideia.

### O controle vem com trabalho

Hospedar por conta própria permite que você tome decisões sobre o ambiente que guarda as suas informações. Também faz de você o responsável por esse ambiente: atualizações, acesso, backups, recuperação e o trabalho comum de manter um serviço no ar.

Ter um servidor não o torna automaticamente seguro. Uma instalação negligenciada não é mais segura só porque pertence a você.

Antes de escolher esse caminho, use as instruções de instalação da versão que pretende rodar, entenda seus requisitos e pense em como se recuperaria de uma falha. Baixar o código é a parte fácil.

O [artigo sobre priorização](/pt/manual/prioritize/) já explica por que incentivo essa independência. Ele também ajuda a explicar nossa preferência por software que continue prático de operar fora da nossa própria configuração.

Se você não quer essa responsabilidade, pagar pela hospedagem também é razoável. Não há prêmio por gastar o seu sábado consertando um servidor quando você queria registrar uma boa lembrança.

Queremos que as duas escolhas façam sentido por si mesmas. Você não precisa se tornar nosso cliente para ser alguém para quem o projeto foi feito.
