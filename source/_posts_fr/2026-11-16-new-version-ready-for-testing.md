Nous sommes heureux de vous annoncer que la nouvelle version est prête à être testée.

Vous pouvez ajouter votre adresse e-mail à la liste d'attente et nous vous laisserons entrer. Gardez à l'esprit qu'il s'agit d'une version de test, et qu'elle n'est pas encore stable. Par ailleurs, les choses vont changer tous les jours, puisque nous fusionnons du nouveau code chaque jour.

Le programme des prochains jours :

- nous espérons que vous nous aiderez à trouver et corriger des bugs,
- nous allons fusionner le nouveau code dans le dépôt de Monica sur GitHub,
- nous allons lancer un nouveau site (et nous en sommes très fiers),
- et enfin, nous allons fermer tous les anciens tickets liés aux versions précédentes du produit.

La liste d'attente est ici : [https://my.monicahq.com/](https://my.monicahq.com/)
