Si vous installez Monica sur un serveur qui vous appartient, vous voudrez sans
doute être prévenu quand une nouvelle version sort. Avec Monica 0.5.0, c'est
exactement ce que vous obtenez.

### Comment cela fonctionne

En résumé, votre instance Monica envoie un ping quotidien à
[https://version.monicahq.com](https://version.monicahq.com). Ce ping contient
trois informations :

- un UUID : l'identifiant unique et anonyme de votre instance,
- la version actuelle de votre instance,
- le nombre de contacts de votre instance.

La dernière information sert à connaître la taille des instances des personnes
qui téléchargent Monica. J'ai besoin de cette information (et uniquement de
celle-là) pour avancer en sachant mieux comment les gens utilisent Monica. Par
ailleurs, il n'y a aucun moyen de savoir qui vous êtes : l'UUID est aléatoire,
unique et anonyme.

Le code de [https://version.monicahq.com](https://version.monicahq.com) est open
source, hébergé [sur GitHub](https://github.com/monicahq/version) comme tout ce
que nous faisons.

En retour de cet appel, vous recevez un JSON avec :

- un booléen indiquant si une nouvelle version est disponible,
- la dernière version disponible,
- toutes les notes de version de chaque publication faite depuis la version du
ping,
- le nombre de versions parues depuis la version du ping.

Ces informations sont utilisées dans l'interface. Dans le pied de page, un
nouveau lien apparaît si une version est disponible. En cliquant dessus, une
fenêtre s'ouvre avec les notes de la nouvelle version.

![pied de page](/assets/images/blog/2017-07-25-v0.5.0-footer.webp)

### Comment désactiver cette fonctionnalité

Toute fonctionnalité qui change le fonctionnement fondamental de Monica peut
être désactivée, et celle-ci ne fait pas exception. Si vous ne voulez envoyer
aucune information à
[https://version.monicahq.com](https://version.monicahq.com), ajoutez
simplement ceci à votre fichier `.env` :

- `CHECK_VERSION=false`

Et c'est tout. Aucune information ne quittera jamais votre serveur.
L'inconvénient est que vous ne serez plus averti automatiquement quand une
nouvelle version paraît.

### Chercher dans vos contacts

Vous pouvez désormais chercher vos contacts grâce à un nouveau champ de
recherche dans l'en-tête. La recherche porte sur les informations suivantes :

- Prénom et nom
- Email
- Rue
- Ville
- Code postal
- Province
- Préférences alimentaires
- Métier
- Entreprise

Les recherches devraient aussi être plutôt rapides. Nous sommes très heureux de
cette fonctionnalité.

### Pour finir

La version 0.5.0 est déjà en production et, comme toujours, vous pouvez
l'installer sur un serveur qui vous appartient.
