Monica 终于迎来了 v1.0.0。

在 Monica，我们尽量遵循 [SemVer 规范](http://semver.org/)。
主版本号的变化意味着 API 有重大改动。所以我非常高兴地宣布 v1.0.0 发布。
它加入了大量功能，也将成为我计划在接下来几个月推出的所有精彩内容的基础。
我们先来说功能，再说这个版本带来的技术改动。

### API

Monica 终于有 API 了。目前还不是所有内容都能通过 API 获取，但联系人的大部分数据已经可以。
后续版本会把设置和账户数据也加进来。我的目标是让所有内容都能通过 API 访问。
我们支持 Oauth 2.0 和个人令牌，底层由 Laravel Passport 处理所有 Oauth 相关的事务。

对开发者来说，再没有什么比一份好文档更能帮助他们上手一个项目。
所以我们也发布了一个[新的文档门户](https://monicahq.com/api/overview)，
力求尽可能完整。每个页面都会标明最后更新日期，让你知道文档有多新。

![Monica API 文档的首页。](/assets/images/blog/2017-11-09-api.webp)

接下来就要看开发者们如何发挥创意，用 Monica 的数据做出精彩的东西了。
我们这边正在开发 Monica 的第一款官方移动应用，同时支持 Apple 和 Android，
更多细节会在今年晚些时候公布。

### 你们是如何认识的（也就是引荐方式）

Monica 的宗旨，是帮助每个人记住身边重要之人的重要信息，私密且仅供你本人查看。
当联系人很多时，有时很难记得是在哪里、如何认识某个人的。
所以你可以记录你是如何认识某人的，或者是由哪位联系人介绍你们认识的。
如果你愿意，还可以设置在这次相遇的纪念日收到提醒。

![联系人的“你们是如何认识的”面板：谁介绍你们认识、什么时候、在哪里。](/assets/images/blog/2017-11-09-introductions.webp)

### 将联系人标记为已故

有时生活并不公平，人会离世。我们增加了将联系人标记为已故的功能，
并可以选填这件伤心事的日期。此外，如果你愿意，还可以为这个日期设置提醒。
联系人被标记为已故后，在整个应用里，他的名字旁边都会显示一个小小的 ⚰。

![一位被标记为已故的联系人，名字旁边有棺材符号，个人资料中显示日期。](/assets/images/blog/2017-11-09-deceased.webp)

### 加快“添加联系人”页面的速度

我们的目标是帮助你尽可能快地完成想做的事。所以我们在“添加联系人”页面加了一个小按钮，
让你保存当前联系人后，立刻接着添加下一个。这会为你节省宝贵的几秒钟。

### 底层的重大改动

在 v1.0.0 中，我们把代码库升级到了 Laravel 5.5，
以便为我们的 API 用上这个版本引入的出色的
[Resources 功能](https://laravel.com/docs/5.5/eloquent-resources)。

感谢 [@mauricew](https://github.com/monicahq/monica/pull/597)，我们还把之前基于 Gulp 和 Bower 的前端构建系统
换成了 mix，也就是 Laravel 现在默认自带的构建系统。我们因此去掉了大量依赖，整理了代码，
更重要的是，确保今后我们的 pull request 中不会再出现 CSS 和 JS 文件的冲突。

### 最后的话

1.0.0 版本已经上线，和往常一样，你可以把它安装在自己拥有的服务器上。

v1.0.0 新增了成千上万行代码。它是一个健康社区的成果。就我个人而言，
能看到 Monica 帮到这么多人，我觉得非常幸运。你们持续的反馈对我帮助极大，
让我能继续尽全力投入这个产品。接下来的几个月会非常忙碌：
更多新功能、一款移动应用，还有其他惊喜。我们社区的未来会很光明。

祝你使用愉快。
