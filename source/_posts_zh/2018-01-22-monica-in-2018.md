每天都在做同一件事的时候，你很少会花时间去想全局。我不想忘记我希望 Monica 实现的目标，所以这里写下我 2018 年想做的事。这篇文章严格来说不是路线图，把它当作我自己的愿望清单就好。

- **发布移动应用**。工作已经开始，我们离应该在未来几周内发布的 v1 很近了。第一个版本是只读的，v2 将允许编辑数据。移动应用的代码[已经在 GitHub 上](https://github.com/monicahq/chandler)，而且是 100% 开源的（当然）。
- **支持 GraphQL**：我们已经有一个 REST API，移动应用的 v1 将使用它。如果我们真想做出一款出色的移动应用，就必须确保向 API 发出的所有请求都足够高效，而 GraphQL 是最好的方案。
- **支持 Carddav 和 Caldav**。我相信这是让 Monica 长期发光的关键。这两种协议能让你把联系人和日历条目，与手机或电脑上现有的邮件和日历应用同步。Monica 将成为你所有社交数据的中心来源。
- **在提醒上多花些心思**，让你可以在事件真正发生之前收到预警。
- **提供关于你社交生活的统计**：某个月你出去了多少次，你见得最多的是谁，你最常去哪里，等等。你给 Monica 的数据越多，得到的洞察就越多。
- **日历视图**，显示提醒、未来的事件等等。
- **“丰富”的活动记录**：比如，如果你记录了去过一家餐厅，就可以设置它在哪里（自动标注在地图上）、吃了什么、花了多长时间，等等。每种类型的活动都有各自需要填写的信息。
- **日记**应该成为你的生活自动记录下来的地方。有了丰富的活动记录之后，这会非常棒。
- **让平台更稳定**，增加大量测试，确保我们在前进的过程中不会弄坏已有的东西。
- 如果我有时间，而且仅限有时间的话：**让应用更好看**。不过我认为，应用好用比好看更重要。
- 最后但同样重要的是：**增加更多导入数据的方式**。这会很痛苦，因为出人意料的是，大多数社交网络或系统都不是开源的，也不会把它们掌握的关于你的数据交给你。

我希望今年能完成以上所有事项。我也知道，各种原因会让情况不断变化，所以请半信半疑地看待它。
