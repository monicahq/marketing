在过去两个月里，我们发布了[一批实用的新功能](https://github.com/monicahq/monica/releases)，但我们对此一直太沉默了。

以下是一些最重要的变化：

- 编辑联系人时，不再自动创建生日提醒：这曾让很多用户感到烦恼。从现在起，当你添加或编辑联系人并填写出生日期时，我们不会再为这个事件自动创建提醒。
- 你所有联系人的债务现在都会显示在仪表盘上。
- 我们加入了 GDPR 合规。这是一项新的欧洲法律，要求我们在注册时确认你的邮箱地址。我本想避免这一点，但在法律上我们别无选择。
- 我们改进了通过 CSV 导入联系人的功能，这个流程现在应该更顺畅了。
- 我们新增了一种联系人之间的关系：前妻或前夫。
- 联系人列表里新增了一个筛选器，可以查看没有关联任何标签的联系人。
- 我们终于支持为联系人设置昵称了。你也可以选择在账户中如何显示姓名。
- 新增 Yubikey 支持，这是又一项安全功能，适合想要额外保护层的人。

另外，Monica 在 Hacker News 上发布已经一年多了。增长相当惊人，尤其是 GitHub 上的社区。现在已经有超过 110 位贡献者帮助构建 Monica，这太棒了。话虽如此，这也有一个代价：我们发布新功能的节奏很快，也正因为这个节奏，我们在最近几个月不够谨慎。Monica 没有达到应有的稳定程度。没有什么严重或致命的问题，但最近两个版本出现了一些本可以避免的低级 bug，我们会采取措施，降低这类情况再次发生的可能。发布没有 bug 的版本尤其重要，因为 Monica 仍然是一个业余项目，最糟糕的情况是在上班时发现平台出了大问题，却要等到有空的时候才能修复并部署到生产环境（通常是我们回到家，还要照顾孩子等等的时候）。相信我，这是日常中你绝不想有的那种担忧。

说了这么多，是想告诉大家，我们会努力把重心放在整体质量上。

请继续通过邮件或在 GitHub 上提交 issue 来发送你的反馈。我们会阅读每一条消息，你的意见对我们很重要（真的）。
