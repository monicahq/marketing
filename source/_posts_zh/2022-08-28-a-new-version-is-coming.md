[Alexis](https://twitter.com/asbin) 和我 [(Regis)](https://twitter.com/maazarin) 已经花了几个月（其实是从 2022 年 1 月开始）在开发一个全新的 Monica 版本。这是自从几年前我们发布以来，真正意义上的第一个全新主要版本。

我很想把它称为“更快、更新、更好的版本”，因为它确实如此，但我不擅长营销，所以我只说这是一个新版本，并在下面回答你可能有的问题。

**我们所说的新版本是什么意思？**

对 Monica 从零开始的彻底重写。

**你们疯了吗？**

是的，但同时，Monica 现在也是一个老代码库了。老的意思是，它已经 7 岁了，经过了数百位贡献者之手。代码里有一些概念，是我们当年要么不知道更好的做法，要么不想得罪贡献者而放行的，现在我们不想再要了。这个项目的依赖实在太多，维护代码比以前更难。改动一点东西风险更大，也更费时间。另外，我们已经看到人们如何使用 Monica、想用它做什么，而如果我们想支持人们使用 Monica 的各种用途，现有的代码给我们的限制实在太多。最后，Monica 对我们来说仍然是个业余项目。我们对它充满热情，也希望在构建它的过程中乐在其中，而当前的版本并没有那么有趣。

**你们所说的重写是什么意思？**

意思是我们从一个空的代码库开始，一切从头来过。以前它是一个 Laravel 应用（也就是 PHP），使用 Blade 视图，并在一些地方用了 Vue。现在它仍然是一个 Laravel 应用（仍然是 PHP），但完全使用 Vue 3。我们简化了很多东西，也让一些东西更灵活，因此稍微复杂了一点，但我们相信它能支撑 Monica 的未来。

这也意味着我们有了全新的数据结构，由新的数据库结构支撑。

**新版本还叫 Monica 吗？**

目前，新 Monica 的代号是 Chandler。不过我们不会保留这个名字，新 Monica 的正式名称仍然是 Monica。为了表述清楚，本文接下来会把新版本称为 Chandler。

**你们选择了 PHP，而不是 \<insert new language/framework> ？**

PHP 是一门很棒的语言。现在早已不是 PHP 4 或 5 的年代了。而且它是一门非常简单的语言，这意味着世界上有很多人能读懂 PHP。选择 PHP 意味着更容易为项目做贡献、更容易调试、更容易维护，将来如果有需要，我们也更容易找到人来帮忙。最后，PHP 生态真的很棒，Laravel 为我所知的最佳开发者体验之一铺平了道路。

**Chandler 会包含哪些功能？**

发布时，我们希望完全（或几乎完全）达到 Monica v1 所提供的功能集。即使是达到同样的功能，我们也希望要么把它们简化（比如任务），要么让它们更健壮（比如提醒）。

完成之后，我们对 Monica 应该成为什么样子有太多想法，多到让人不知所措。简单来说，Monica 诞生时是第一个个人 CRM（或者 PRM，即个人关系管理器），所以我们就这样给它定位。但在做了这么多年、和大家交流，并读了你们发给我们的成千上万封邮件之后，我们意识到，Monica 其实是一种记录你生活的方式，不管这对你意味着什么。所以，Monica 将致力于记录你的生活，并提供工具，帮你按自己想要的方式去记录。

我们到处都能读到，产品应该有主张、有强烈的个性，这样人们才会按你希望的方式使用你的工具。这就是 v1 的方向。现在我们想改变这个说法。我们希望人们按自己想要的方式使用和配置 Monica。我们凭什么告诉你，你的联系人只能用 3 种代词，或者告诉你应该有哪些关系类型？Chandler 将可以完全自定义，从你在界面上看到的内容，到你可以录入的数据类型。做营销的人会说“Chandler 一切以你为中心”，从某种意义上说，这是真的。代价是：从技术角度来看，它更难管理，但这是我们要承担的。

**什么时候能准备好？我可以试用吗？**

准备好了自然就会好。请记住，我们完全不是全职做这件事。Alexis 和我都有繁重的日常工作，还有家人、朋友，还有 Monica（以及 OfficeLife）。

不过。

我们已经做了很多。一些你熟悉并喜爱的重要功能，新版本里还没有：生活事件、活动、礼物和 CalDav/CardDav，等等。尤其是生活事件，是个大工程，因为我们想彻底重新思考这个概念，让它真正有用。还有，这是个很大的“还有”，目前我们还没有 API。由于这是一个新的代码库，我们不能简单地把你现有的 v1 联系人复制粘贴过来，指望它们在 v2 中显示。所以，如果我们现在就发布，你无法导入自己的数据。我们认为这是个问题。

话虽如此。

我们仍然需要测试人员来帮助我们找出 bug，尽管我们这里不出 bug（哈哈）。我们也需要有人帮忙修正文档里的拼写错误。所以我们可以做的是，以非常早期的 alpha 状态发布 Chandler，在 alpha 结束之前对所有人免费。

**它仍然是开源的吗？我可以免费使用吗？**

是的，它仍然是开源的，许可证与以前相同。这意味着 Monica 当然是免费的，除非你使用我们托管的版本，那最终会像当前版本一样收取一些费用。是的，你可以把它安装在你喜欢的任何地方，比如你自己的服务器上。由于 Chandler 不是同一个代码库，我们还没有以前那样丰富的生态，也没有那么多可以随处安装的方式，但我们会做到的。是的，你仍然可以为代码做贡献、修复 bug、添加功能，不过如果我们认为不想支持你希望我们支持的东西，我们仍然有权拒绝你的 pull request。

**Monica v1 的未来会怎样？**

在 Chandler 走出 alpha/beta 阶段之前，我们会继续支持 v1。之后它将被弃用，但自己托管过它的人如果愿意，可以继续使用。我们自己托管的 v1 版本此后将不再受到支持。

**现在可以为这个代码库做贡献了吗？**

这个仓库已经[在 GitHub 上公开](https://github.com/monicahq/chandler)，但它的成熟度还远不及当前的主仓库。这意味着我们还没有准备好支持每个人的贡献，因为几乎每天都有变动，不过如果你能接受这一点，请尽管来。

**接下来呢？**

首先，非常感谢你把这篇博客读完。我们非常感激我们的社区，感激你们依然对这个我们乐在其中构建的小工具充满热情。Alexis 和我仍然对这个工具充满动力，感谢你们和我们一起关心它。我们会保持联系。
