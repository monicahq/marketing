好久不见了。确切地说，距离上一篇博客已经过去一年。这篇文章会聊聊我们刚刚发布的 2.16 版本，2019 年发生了什么，以及 Monica 接下来的方向。

2.16 版本包含 226 项更改，其中大部分是错误修复或对代码库的改进。不过也有一些新功能，下面逐一说明。

### 添加活动的新方式

现在你可以直接在页面内添加活动，不必再跳转到新页面。和通话功能一样，你也可以标明在一次活动中的感受。

![为联系人添加活动的表单，询问你做了什么、什么时候做的。](/assets/images/blog/2019-12-31-inline-activities.webp)

### 改进 API 设置页面

你在 Monica 中能做的大部分事情，都可以通过 API 完成。让人们随心所欲地处理自己的数据，对我们来说极其重要。所以是时候多花点心思，改进一下 API 设置页面了。

![API 设置界面，显示个人访问令牌和 OAuth 客户端。](/assets/images/blog/2019-12-31-api.webp)

此外，我们还加入了[许多新的 API 方法](https://github.com/monicahq/monica/pull/3302)，继续保持对其他系统的开放。

### 底层的大量改动

我们还彻底改变了数据的存储方式，为数据库中的每张表都加上了外键。这对最终用户的体验没有影响，但对我们开发者来说意义重大，因为它让我们整体上拥有更多的控制力和灵活性。这对我们是一次巨大的改动，相关的 pull request 花了将近 11 个月才合并。

我们还彻底改变了数据导出的处理方式，从现在起它应该能完美运行（或者像大家说的：60% 的时候，它每次都能用）。

### 2019 年发生了什么？

2019 年，我们在年度发布上稍微放慢了脚步，这个博客也毫无动静。不过，这并没有影响注册人数、下载量，也没有影响网上的人们对这个项目的喜爱。

总的来说，Monica 从未像现在这样强大。我们官方 Docker 镜像的下载量已接近 500 万次。[我们的托管版本](https://app.monicahq.com)有数万名用户。Monica 不断出现在 [Hacker News](https://news.ycombinator.com/item?id=21850155) 上，[我们在 GitHub 上的 issue 跟踪器](https://github.com/monicahq/monica/issues)也和以往一样活跃。另外，我们在 2019 年合并了 875 个 pull request。

那为什么这么沉默？主要是因为我（Regis）。我启动 Monica 已经快四年了。拥有一个受欢迎的项目很有趣，但也需要大量的精力和动力，尤其是因为 Monica 对我和 Alexis 来说仍然是个业余项目。但今年，Monica 对我来说负担太重了，而平时在这个博客或社交媒体上写东西的，通常就是我。可以说，我遇到了业余项目的倦怠期。Alexis 肩上扛起了大量工作来维护和推进产品，但我无法再像以前那样投入，也没法发布任何关于项目的消息。我必须去做些别的事，让头脑放空，等准备好了再回来。现在我准备好了，也非常有动力重新投入工作，重新找回乐趣。

### 2020 年的 Monica

四年前，Monica 是最早流行起来的个人 CRM 之一。到了今天，竞争比以往任何时候都更激烈（我上次查看时有十几个）。但我相信，我们拥有竞争对手无法超越的优势：我们是开源的，几乎没有任何费用和成本，而且我们并不贪心。我们所做的一切，首先都是为了社区。外面的 Monica 实例越多，我们就越高兴：这意味着我们无法掌控用户的数据。

2020 年：

- 我们想继续推进开放和透明的工作。这意味着提供更多以标准格式导出或导入数据的方式。
- 我们想提供 webhook，这样当你账户中的数据发生变化时，外部系统可以得到通知（当然，前提是你愿意）。
- 我相信 Monica 目前是记录个人联系人的最佳工具，你真的可以记录任何内容。既然我们已经有了非常坚实的基础，我认为是时候在此之上拓展了。是时候让你能用联系人做更多事情了，比如创建群组（或家庭）、事件、机会等等。我们会专注于简单的概念，并逐步加入平台，让你获得最大的灵活性。

Monica 是为你而做的工具。请继续分享你的想法，继续给我发邮件，告诉我们下一步该做什么。我们一直在这里。

另外，新年快乐。
