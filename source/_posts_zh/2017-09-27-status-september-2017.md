过去 40 天里，我在沟通方面不太活跃，回复 issue 和合并 pull request 也比以前慢。我并不喜欢这种状况，但在接下来一个月左右，我很难改变它。不过，情况会好起来的。

## 我现在到底在忙什么

我在尽可能多地投入这个项目。我所有的空闲时间都花在了 Monica 上。有不少人一直给我发邮件，问我是否还会继续投入这个项目、会不会很快放弃。在这里让大家放心：我对它的热情一如既往，它依然是我的优先事项。

不过，我目前正在做 API，确保它按预期工作。我也在编写相关文档，因为想让人们用起 API，文档必须做到出色。出于这些原因，也因为在我找到办法把它变成全职工作之前，它仍然是一个业余项目，所以我现在不想被反馈、bug 或新功能分散精力。API 一做完，我就会回头继续回应社区。遗憾的是，我实在没有足够的时间去做我想做的所有事，如果想把事情做成，我就必须非常专注。

## 接下来

未来几天，API 的第一版草稿会发布，之后还会陆续增加新的方法。

API 完成后，我们需要把重心放在与联系人一起进行的活动这个概念上，好好打磨一番。我们还应该让仪表盘更有用，并改造日记，让它真正变得有用。另外，我们需要实现 Carddav 协议，不过目前我还不确定它能与现有技术栈整合到什么程度。

我相信这个项目有巨大的潜力。如果你是现有用户，我仍在征集[反馈和用户评价](https://docs.google.com/forms/d/e/1FAIpQLSfaAds4I5F9zLisQpC221pcF0KEkjTPH-koN96D64QFem6uZg/viewform?usp=sf_link)。感谢你的帮助。
