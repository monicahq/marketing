自 2017 年 6 月公开发布以来，我几乎每天都会收到询问移动应用的邮件。

我理解为什么。Monica 有一个移动应用，实在太合理了。你希望无论身在何处，都能在恰当的时刻立刻获取这些信息，而不是只有坐在家里的电脑前才行。

我们 6 个月前就开始开发移动应用了。这是很长的时间。不过，我想大多数人并不清楚发布一个移动应用需要做多少工作，尤其是当 99.9% 的代码出自一个人之手（了不起的 @mokto），而他有一份全职工作，也没有为此获得报酬。

在这几个月里，我们投入了大量精力，来打造移动应用所需要的一切。为了支持某些功能，API 发生了很大变化。我们稳定了后端，确保它能完美运行。我们还花了很多时间在 GitHub 上的移动应用仓库里把一切都按正确的方式搭建好，这将让我们今后推进得更快（这里说的是出色的 CI、单元测试、自动发布到应用商店等等）。

六个月后，我们自豪地宣布，移动应用的第一个版本已经可以在 [iOS](https://itunes.apple.com/ca/app/monica-personal-crm/id1339447754?mt=8) 和 [Android](https://play.google.com/store/apps/details?id=com.monicahq.app) 上使用。

![三部手机上的 Monica 移动应用：某位联系人的资料页、空的联系人列表，以及活动页面。](/assets/images/blog/2018-05-28-mobile-app.webp)

不过有一点需要说明：*第一个版本是只读的*。也就是说，你不能添加或编辑任何内容。我们想做出一个出色的应用，但我们希望走得慢一些，确保它运行良好。一旦我们确信这个版本对所有人都可靠，就会加入让你完全按自己意愿操作数据的功能（提示：我们已经开始开发新版本了）。

除此之外，这个移动应用具备你对我们所期待的一切：

- 简单友好的用户界面。
- 你可以连接我们的托管版 Monica，也可以登录你自己的实例。
- 代码是开源的。你可以阅读代码、提交 issue、为代码做贡献。我们做的一切都是开放透明的，我们相信只有协作才能做出最好的产品。
- 开源意味着你可以*自行构建并运行移动应用，而无需经过苹果和谷歌的官方应用商店*，在我看来，这相当了不起。
- 我们不展示广告，也不转售你的数据。
- 我们的代码里没有任何追踪。
- 这个应用是免费的，没有任何附加条件。

### 你可以怎样帮忙？

基本上，我们需要有人来测试这个应用，并[告诉我们是否有 bug](https://github.com/monicahq/chandler/issues)。另外，我们也想听听你的看法：接下来我们应该开发什么，或者怎样才能让应用变得更好（无论是用户体验还是布局方面）。

### 接下来是什么？

在接下来的几天里，我们会改进官方 GitHub 仓库上的文档，让想要帮忙的开发者能轻松加入这个项目。

在接下来的几个月里，我们会加入在移动应用中修改数据的功能。最终目标是，你在网页上能做的一切，在手机上也能做到（导出数据除外，因为比如在 iOS 上，你要把文件存到哪里呢……）。这也是我们现在先在 API 中构建功能，再构建界面（网页和移动端）的原因。

最后，我想说，我为我们迄今取得的成就感到非常自豪，更为每天都在帮助我们的社区感到自豪。你们的反馈和帮助，让 Monica 成为可能。
