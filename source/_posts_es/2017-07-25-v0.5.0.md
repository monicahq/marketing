Si instalas Monica en un servidor propio, lo más probable es que quieras
enterarte cuando haya una versión nueva. Con Monica 0.5.0 tienes exactamente
eso.

### Cómo funciona

En resumen, tu instancia de Monica envía un ping diario a
[https://version.monicahq.com](https://version.monicahq.com). El ping contiene
tres datos:

- un UUID: el identificador único y anónimo de tu instancia,
- la versión actual de tu instancia,
- el número de contactos de tu instancia.

El último dato sirve para conocer el tamaño de las instancias de quienes se
descargan Monica. Necesito ese dato (y solo ese) para avanzar sabiendo mejor
cómo se usa Monica. Además, no hay manera de saber quién eres: el UUID es
aleatorio, único y anónimo.

El código de [https://version.monicahq.com](https://version.monicahq.com) es de
código abierto y está [en GitHub](https://github.com/monicahq/version), como
todo lo que hacemos.

Como respuesta a esa llamada, recibes un JSON con:

- un booleano que indica si hay una versión nueva,
- cuál es la última versión disponible,
- todas las notas de publicación de cada versión lanzada desde la versión del
ping,
- el número de versiones publicadas desde la versión del ping.

Esta información se usa en la interfaz. En el pie de página aparece un enlace
nuevo si hay una versión disponible. Al hacer clic se abre una ventana con las
notas de la nueva versión.

![pie de página](/assets/images/blog/2017-07-25-v0.5.0-footer.webp)

### Cómo desactivar esta función

Toda función que cambie el funcionamiento esencial de Monica puede desactivarse,
y esta no es una excepción. Si no quieres enviar ninguna información a
[https://version.monicahq.com](https://version.monicahq.com), simplemente añade
esto a tu archivo `.env`:

- `CHECK_VERSION=false`

Y ya está. Nunca saldrá información alguna de tu servidor. El inconveniente es
que no recibirás avisos automáticos cuando salga una versión nueva.

### Buscar entre tus contactos

Ahora puedes buscar entre tus contactos con un nuevo cuadro de búsqueda en la
cabecera. La búsqueda tiene en cuenta los siguientes datos:

- Nombre y apellidos
- Correo electrónico
- Calle
- Ciudad
- Código postal
- Provincia
- Preferencias alimentarias
- Puesto
- Empresa

Las búsquedas deberían ser además bastante rápidas. Nos hace mucha ilusión esta
función.
