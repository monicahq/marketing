First of all, the goal of this project is not to make money. The primary goal is to create a tool that we need, to learn new programming techniques, to improve what we already know, and to have fun. It's our way of releasing the pressure of our other real jobs. Monica is given for free as an open source tool, and you can install, modify or delete whatever you want and do whatever you want with it and I have no problem with that.

But considering the extreme amount of time we put into trying to create a nice tool for everyone and not just for me, it'd be nice if it brought some money too so we can buy a new computer, a new bike or a new gadget. And not just for that. Yes, hosting the database itself costs almost nothing, but we still need to pay for the system that sends reminders and other services which, unfortunately, have a monthly fee attached to them.

This project makes money by selling access to the instance of Monica that we host. You can pay monthly, yearly, or once for lifetime access, and you are never locked in. It's simple, really.

This is one of the reason the software is open source. If this site is ever shut down, you'll still have the software available on GitHub and elsewhere. Anyway. Host your software yourself. Pay and use the version we host. We don't care as long as you are happy.

### A note on VC

How can I put this as delicately as possible? Fuck VC money. Yeah, I think that's a delicate way of putting it.

Over the years, we've spent some time answering emails and attending calls with VCs. This is such a waste of time. They don't ever want to actually invest. They just want to understand why the product is a success and what is the market size. Not a single one of them had an ounce of respect for user privacy.

Money is great, but independence and having to answer to no one is invaluable. Or is worth 50 millions, but no less.
