Monica is a side project made by two people, Régis and Alexis. Régis started it in 2017, and we believe it was the first personal CRM. Alexis joined in 2018, first as a contributor, then as the person who keeps Monica installable, upgradable and running on other people's machines.

Régis writes the features (and most of the bugs). His passion, when he gets back from his real work (the one that pays the bills), is to code and learn new things every day. This is how he relieves the stress of a challenging day job, which is not about code at all. Alexis works on the infrastructure and the really hard things: the Docker images, the releases, and everything that only breaks on somebody else's server. Monica is where that time goes.

We still think nobody has figured out how to effectively document personal lives and share what we know about people we like. Monica is our attempt to solve this puzzle. It's also a way for us to learn new technologies and, more importantly, to explore how far we can push simple technologies to achieve significant results without relying on complex, hard-to-maintain JavaScript frameworks, which Régis personally doesn't like at all.

Monica is a side project. We work a lot on it, but we work on it at night and on the weekend. We try to fix bugs as soon as we see them. We will not implement all the features people want. Do not expect professional, 24/7 support: we don't have the time for this. We try to limit as much as possible how people can contact us, since it takes so much time otherwise, and we want to dedicate our time to working on the product as much as possible.

We believe in open source. We use many OSS tools every day. We need to make money to run this project, and also to help justify the (significant) personal time we put into it, but it's not the driving force behind the project. We like closed source projects too. We're not purists. But we use so many open source projects that we need to give back somehow. Also, would you trust a closed source project to store this kind of data? Lol.

We have launched this project for the journey, not the destination. We're not sure where it will go. We're not sure if it will be a success. But we're sure it will be a fun ride.
