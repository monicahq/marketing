You can have open source software and still have a hosting bill. A surprising number of discussions about software economics would be shorter if we started there.

Making Monica available under an open source licence doesn't make servers, email delivery, maintenance, or people's time free.

It gives people freedoms over the software. It doesn't persuade a service provider to accept goodwill as payment.

### Hosting is work too

The [money article](/en/handbook/money/) describes how the project earns revenue from the version we host. Paying for that service means paying for convenience and the work around running it, rather than buying exclusive ownership of the code.

Self-hosting moves some of those responsibilities to you. It can be the right choice, but the work doesn't cease to exist because you do it yourself. Your time counts even if it doesn't appear on an invoice.

Development is another cost. A feature can take many evenings to get right, then require attention for years. [The invisible maintenance work](/en/handbook/invisible-work/) is part of that economy too.

I don't think there is a contradiction between sharing the code and asking people to pay for a useful service built around it. A sustainable project is more likely to keep producing software people can use.

Nor does paying make someone morally superior to a self-hosting user. These are different arrangements, not different levels of virtue. Use the one that fits your life.
