Monica ist endlich bereit für v1.0.0.

Wir versuchen bei Monica, dem [SemVer-Ansatz](http://semver.org/) zu folgen.
Eine neue Hauptversionsnummer weist auf große Änderungen an der API hin. Deshalb
freue ich mich sehr, die Veröffentlichung von v1.0.0 anzukündigen. Sie bringt
viele Funktionen und dient als Fundament für all die schönen Dinge, die ich in
den kommenden Monaten ausliefern will. Sprechen wir zuerst über die Funktionen
und dann über die technischen Änderungen dieser Version.

### Die API

Monica hat endlich eine API. Noch ist nicht alles darüber erreichbar, aber die
meisten Daten über Kontakte sind es. Eine künftige Version bringt auch die
Einstellungen und Kontodaten. Mein Ziel ist, dass alles über die API verfügbar
ist. Wir unterstützen OAuth 2.0 und persönliche Token. Im Hintergrund kümmert
sich Laravel Passport um alles rund um OAuth.

Nichts hilft Entwicklern mehr beim Einstieg in ein Projekt als eine gute
Dokumentation. Deshalb haben wir auch ein [neues
Dokumentationsportal](https://monicahq.com/api/overview) veröffentlicht, das so
vollständig wie möglich sein will. Auf jeder Seite geben wir zudem das Datum der
letzten Aktualisierung an, damit Sie wissen, wie aktuell sie ist.

![Die Startseite von Monicas API-Dokumentation.](/assets/images/blog/2017-11-09-api.webp)

Nun liegt es an den Entwicklern, kreativ mit Monicas Daten umzugehen und
Großartiges damit anzustellen. Auf unserer Seite arbeiten wir an der ersten
offiziellen mobilen Anwendung für Monica, für Apple und Android, doch dazu gibt
es später im Jahr mehr Einzelheiten.

### Wie Sie jemanden kennengelernt haben

Monica soll allen helfen, sich an wichtige Informationen über die Menschen zu
erinnern, die ihnen wichtig sind, privat und nur für Ihre Augen. Wenn man viele
Kontakte hat, fällt es manchmal schwer, sich zu erinnern, wie und wo man sie
kennengelernt hat. Deshalb können Sie angeben, wie Sie jemanden kennengelernt
haben oder ob ein anderer Kontakt Sie vorgestellt hat. Auf Wunsch können Sie
sich sogar an den Jahrestag dieser Begegnung erinnern lassen.

![Der Bereich „Wie Sie sich kennengelernt haben“ eines Kontakts: wer Sie vorgestellt hat, wann und wo.](/assets/images/blog/2017-11-09-introductions.webp)

### Einen Kontakt als verstorben markieren

Manchmal ist das Leben ungerecht und Menschen sterben. Wir haben die
Möglichkeit ergänzt, einen Kontakt als verstorben zu markieren und ein optionales
Datum für dieses traurige Ereignis anzugeben. Zudem können Sie sich daran
erinnern lassen, wenn Sie möchten. Ist ein Kontakt als verstorben markiert,
erscheint in der gesamten Anwendung ein kleines ⚰ neben seinem Namen.

![Ein als verstorben markierter Kontakt, mit einem Sarg neben dem Namen und dem Datum im Eintrag.](/assets/images/blog/2017-11-09-deceased.webp)

### Der Bildschirm zum Anlegen von Kontakten wird schneller

Unser Ziel ist, Ihnen so schnell wie möglich zu dem zu verhelfen, was Sie
vorhaben. Deshalb haben wir auf dem Bildschirm zum Anlegen eines Kontakts eine
kleine Schaltfläche ergänzt, mit der Sie den aktuellen Kontakt speichern und
direkt danach einen weiteren anlegen. Das spart kostbare Sekunden.

### Große Änderungen unter der Haube

Für v1.0.0 haben wir die Codebasis auf Laravel 5.5 gehoben, um für unsere API
die großartige [Resources-Funktion](https://laravel.com/docs/5.5/eloquent-resources)
dieser Version zu nutzen.

Dank [@mauricew](https://github.com/monicahq/monica/pull/597) haben wir zudem
das bisherige Frontend-Build-System auf Basis von Gulp und Bower durch mix
ersetzt, das Standard-Build-System, das Laravel inzwischen mitbringt. Wir konnten
viele Abhängigkeiten entfernen, den Code aufräumen und vor allem sicherstellen,
dass es künftig keine Konflikte bei CSS- und JS-Dateien in unseren Pull Requests
gibt.

### Zum Schluss

Version 1.0.0 ist bereits in Produktion und wie immer können Sie sie auf einem
eigenen Server installieren.

v1.0.0 umfasst buchstäblich Tausende neuer Codezeilen. Sie ist das Ergebnis
einer gesunden Gemeinschaft. Persönlich empfinde ich es als großes Glück, dass
Monica so vielen Menschen hilft. Ihre fortwährenden Rückmeldungen helfen mir
enorm dabei, weiterhin so hart wie möglich an diesem Produkt zu arbeiten. Die
kommenden Monate werden sehr voll: viele neue Funktionen, eine mobile Anwendung
und weitere Überraschungen. Die Zukunft unserer Gemeinschaft wird strahlend.

Viel Freude damit!
